# Homework -- Chapter 02, Problem 10: The Full Guessing Game

The notes built the guessing game in four versions: read a
guess, generate a random number, compare with `Ordering`, and
finally loop until winning. This problem reassembles everything
into one program -- plus a few twists that stay strictly within
the notes' material.

## Setup

Build it as a cargo project (you already know the drill from
Problem 5):

    cd homework/chapter02
    cargo new hw_game --vcs none

Add `"homework/chapter02/hw_game"` to the workspace `members`,
add `rand = "0.8.5"` to its `Cargo.toml`, and verify with
`python3 doctor.py --workspace`.

## Requirements

Write `hw_game/src/main.rs` so that:

1. It generates a secret number in `1..=100` (do NOT print it --
   unlike the notes' version, keep it secret).

2. It loops: prompts, reads a line, and handles input with a
   `match` on `parse()`'s `Result` -- invalid input re-prompts
   via `continue`, no crashing, no `.expect` on the parse.

3. On a valid guess it matches on `guess.cmp(&secret)` and
   prints "Too small!", "Too big!", or "You win!" -- and breaks
   on winning.

4. Twist 1 -- guess counter: count how many guesses the player
   needed, and on winning print:

       You win! (attempts: N)

5. Twist 2 -- give up: if the player types "giveup" (trimmed,
   case-sensitive), the program prints the secret and exits:

       The secret was: S. Better luck next time!

   (Reading a non-number now goes through your `match` as the
   `Err` arm -- decide where "giveup" fits: before the parse,
   on the string, is easiest.)

6. Twist 3 -- replay: after "You win!", ask "Play again? (y/n)".
   On "y" start a fresh round with a NEW secret number; on
   anything else print "Thanks for playing!" and exit. This
   needs the whole game inside an outer `loop` -- everything
   you need (`loop`, `break`, `continue`, shadowing) is in the
   notes.

## Self-review checklist

After it works, check each box in a comment at the top of
`main.rs`:

- [ ] `use std::io;`, `use std::cmp::Ordering;`, `use rand::Rng;`
- [ ] secret not printed until win/giveup
- [ ] invalid input never panics (match on Result, continue)
- [ ] attempts counter resets each round
- [ ] "giveup" reveals the secret and exits cleanly
- [ ] replay loops with a fresh secret
- [ ] no compiler warnings (`cargo check` is clean)

Play a couple of games to make sure the flow feels right.
